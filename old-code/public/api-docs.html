🔌 Tectobox Public API

Integrate your website, app or ERP with Tectobox in minutes. Read conversations, send replies, pull leads and products, and receive real-time event webhooks — all scoped to your workspace.

1. Get an API key

In the dashboard, open your workspace Connectors tab → API keys → Create key. The raw key is shown once — copy it immediately. It looks like tk_9f2c…. Treat it like a password.

2. Authenticate

Send the key as a Bearer token on every request:

curl -H "Authorization: Bearer tk_YOUR_KEY" \
  https://ss.kalandar.me/api/v1/conversations?limit=10

3. Endpoints

GET/api/v1/conversations

List conversations. Query params: platform (messenger/instagram/telegram/whatsapp), q (search), limit (default 50, max 200).

GET/api/v1/conversations/:id/messages

Message history for one conversation. Query param: limit (default 100, max 500).

POST/api/v1/conversations/:id/reply

Send a reply as your business. JSON body: {"text": "…"} (max 4000 chars). The message is delivered on the conversation's original platform.

curl -X POST -H "Authorization: Bearer tk_YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"text":"Thanks for reaching out! How can I help?"}' \
  https://ss.kalandar.me/api/v1/conversations/42/reply
GET/api/v1/leads

Your leads pipeline. Query param: limit (default 50, max 200).

GET/api/v1/products

Your product catalog. Query param: q (search).

4. Webhooks — real-time events

Register a URL in Connectors → Webhooks to receive signed POSTs when things happen:

  • message.received — a customer messaged you
  • lead.created — a new lead entered the pipeline
  • order.created — an order was placed

Every delivery carries X-Tectonic-Event and X-Tectonic-Signature: sha256=… headers. Verify the signature with the signing secret shown at registration:

// Node.js signature verification
const crypto = require('crypto');
const sig = req.headers['x-tectonic-signature']; // "sha256=…"
const expected = 'sha256=' + crypto.createHmac('sha256', SIGNING_SECRET)
  .update(JSON.stringify(req.body)).digest('hex');
const ok = crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected));

Payload shape:

{
  "event": "message.received",
  "client_id": 3,
  "at": "2026-09-30T16:40:00.000Z",
  "data": { "conversation_id": 42, "platform": "messenger",
            "platform_user_id": "123", "text": "Price?", "message_id": 9001 }
}

5. Limits & safety

  • 300 requests/minute per API key; 600 requests/10 min per IP on the API.
  • Keys are workspace-scoped — a key can never see another business's data.
  • Revoke a leaked key instantly from the dashboard; it stops working immediately.
  • Webhook URLs must be public https endpoints (private/loopback targets are rejected).
